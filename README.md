# KL AI 실습

KL AI 실습 교육에서 쓰는 앱의 설치 파일을 올려 두는 곳입니다.

**[최신 버전 내려받기](https://github.com/kapitalletter/kl-ai-lab-releases/releases/latest)**

- **Mac (Apple 실리콘)**: `KL-AI-Lab-darwin-arm64.zip`을 받아 풀고, `KL-AI-Lab`을 '응용 프로그램' 폴더로 옮긴 뒤 여세요.
- **Windows**: `KL-AI-Lab-win32-x64-setup.exe`를 실행하세요. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.

한 번 설치하면 새 버전이 나왔을 때 앱이 알려 주고, "지금 업데이트"를 누르면 바로 바뀝니다.
